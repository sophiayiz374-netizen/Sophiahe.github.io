Sophia He — UX Portfolio (Figma interaction pass)

This is a static HTML/CSS/JavaScript website for GitHub Pages.
- index.html: homepage with hover feedback, scroll reveal, project links, responsive menu, and persistent dock navigation.
- case-*.html: project pages with interactive step tabs and previous/next controls.
- styles.css / script.js: responsive styling and interaction behaviour.
- assets/: exported visual assets from the supplied Figma asset pack.

Publish:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder (not the outer folder) to the root of the Sophiahe.github.io repository.
3. Commit changes to main.
4. Settings > Pages > Deploy from a branch > main > /(root).
5. Wait for deployment, then refresh the Pages URL.

Before sharing publicly:
- Replace YOUR_EMAIL@example.com in index.html with your preferred contact email.
- Review project descriptions, roles, dates, and any anonymization requirements.
- The case-study walkthroughs reproduce the main interactive browsing patterns using the exported Figma visuals. They are a web adaptation, not a pixel-perfect runtime export of Figma's prototype engine.
