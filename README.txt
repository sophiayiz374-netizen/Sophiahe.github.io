Sophia He — UX Portfolio website starter

Files:
- index.html: homepage
- styles.css: responsive styles
- script.js: small navigation interactions
- case-*.html: project detail pages
- assets/: images exported from the supplied Figma asset ZIP

To publish:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder (not the outer folder) into the root of the Sophiahe.github.io GitHub repository.
3. Commit the upload.
4. In GitHub, open Settings > Pages. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the GitHub Pages deployment to finish, then visit https://sophiahe.github.io/

Note: The case-study detail pages are a first-pass structure. Replace YOUR_EMAIL@example.com with your real contact email, and confirm the full case-study copy, role, and dates before treating the portfolio as final.
